# neco-cad-import

[English](README.md)

`neco-cad-import` は、閉じた向き付きのメッシュと、検査済みの解析的なシェルから、証明付きの領域を構成します。

## 主要機能

**メッシュの取り込み**

閉じた向き付きの曲面メッシュを、要求する誤差の上限と、半直線との交差の判定方針とともに受け取り、証明付きの領域を返します。

**シェルの取り込み**

解析的な境界表現の中から名前で指定したシェルを検査し、閉じていること、向き、多様体であること、トリム、交差の五つの観点のすべてで証拠がそろった場合に、証明付きの領域を返します。呼び出し側は、式の厳密な判定に関わる三つの値を渡します。半直線との交差を判定する各対象 ( メッシュの各三角形、またはシェルの各面 ) は、これらの値をそのまま保持します。

- `OwnerId`: 式の集合の所有者の識別子
- `ExactExpressionRequirement`: 式の厳密な判定の要求。消費点 ( 結果を受け取る利用箇所 ) の識別子、対象の式の一覧、判定 ( 判定の種類と、一覧から選んだ判定の対象の式 ) 、精度から成る
- `NecoImplementationSource`: 厳密計算の実装 neco-expr の版と、その公開 API の識別子

**所属判定**

座標が有限である点を、その点から X 軸の正の向きへ伸ばした半直線と、要求で指定した判定方針を使って、領域の内部、外部、境界のいずれかに分類します。このとき、呼び出し側は、呼び出しのたびに、上に挙げた三つの値を渡します。結果は、分類、交差の数、判定が定まらなかった場合の型付きの証拠を保持します。

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-cad-import = "0.3"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。

```toml
[dependencies]
neco-cad-import = { version = "0.3", default-features = false }
```
