# neco-cad-view

[English](README.md)

`neco-cad-view` は、CAD の結果を表示するための表示モデルと、CPU で計算する参照投影を提供します。
表示モデルは、境界表現の導出元の版 ( source revision ) を記録します。導出元の版は、呼び出し側が構築要求に付ける版の文字列です。

## 主要機能

**表示モデル**

表示モデルは、面分割後の形状と要素の識別子を、その版とともにまとめたモデルです。

**参照投影**

参照実装として、表示モデルを CPU で投影します。

**要素の特定**

投影後の座標から、対応する境界表現の要素を特定します。

## 精度と識別子

表示モデルは、基本の面分割と適応面分割のどちらか一方の結果から導出され、メッシュ、各要素の対応関係、精度の状態を持ちます。導出では、まず導出元の版と精度の要求をそれぞれ検査し、その後で共通の規則により要素を対応付けます。モデルからは、精度の要求値と、証明付きの上界を別々に読み出せます。

* `CadViewModelRequest`: 面分割の種類を示した入力と、表示の状態をまとめた導出の要求
* `Basic`: 要求された弦誤差だけを記録し、証明付きの上界を持たない面分割の種類
* `NotEstablished`: 要求された弦誤差だけを持つ、基本の面分割の精度の状態
* `TessellationResult`: 基本の面分割が生成したメッシュと要素の対応関係
* `TessellationRequest`: 基本の面分割に渡す弦誤差の要求
* `Adaptive`: 証明付きの精度の証拠を持つ面分割の種類
* `AdaptiveTessellation`: 適応面分割が生成したメッシュ、要素の対応関係、証拠
* `AdaptivePrecision`: 面分割の用途 ( 表示、解析、要素の特定 ) と、弦誤差の上限、曲面残差の上限
* `SourceRevision`: 表示モデルの導出時に照合する、境界表現の導出元の版
* `SourceIdentity`: メッシュの識別子。適応面分割の要求で呼び出し側が付ける、生成メッシュの名前
* `ViewModelIdentity`: 導出元の版と、省略可能なメッシュの識別子を別々に公開する値
* 適応面分割の証拠: 各三角形の辺の弦誤差の上界と、各頂点の曲面残差を厳密な二進有理数で表した上界

曲面残差 ( surface residual ) は、面が載る曲面を $f = 0$ と表す関数 $f$ の、頂点での値の絶対値です。その上界は、頂点の厳密な座標を囲む二進有理数の区間で求めます。

CPU による参照投影では、導出した表示モデルを入力に使います。要素の特定に使う入力は、その参照投影の結果です。

## カメラの数値計算の仕様

透視カメラの画角 $\theta$ には、垂直方向の全画角をラジアンで指定します。カメラは、有限で $0 < \theta < \pi$ を満たす値を受理します。深さ $z$ における可視範囲の高さの半分は $z \tan(\theta/2)$ で、幅の半分は、この値にビューポートの縦横比を掛けた値です。レイ ( ray ) の生成、CPU による投影、視錐台の上下左右の面による切り取りが使う正接は、いずれもカメラの構築時に一度だけ求めた値です。

画素の座標には、画素の中心を表す 0.5 のオフセットを加えます。例えば、100 × 100 のビューポートと全画角 $\pi/2$ を指定し、カメラを負の z 方向へ向けると、レイの方向と画面の端は次の値になります。

* 画素 ( 0, 49.5 ) を通るレイの方向の比 x/z は、0.99 になる
* 画面の端は、座標 -0.5 と 99.5 に対応する

カメラの演算は、二つのランタイム構成のどちらでも同じ倍精度演算を使います。画角が $\pi$ に近い場合も同じ演算経路を通り、入力された倍精度の角度の正接を評価します。演算が失敗した場合は、投影、画角、レイのどこで失敗したかを区別できる値を返します。

* 演算: `libm` の正接と平方根
* 投影の失敗: 正接が 0 に丸められた場合、または投影した座標が非有限になった場合は `NonFiniteCoordinate`
* 画角の失敗: 定義域外または非有限の角度には `InvalidPerspectiveFieldOfView`
* レイの失敗: 非有限の値に対しては、元の `GeometryFailure` を保持する

適応面分割の精度の証拠は、面分割した形状の弦誤差の上界と曲面残差の上界だけを対象とします。一方、カメラの浮動小数点演算には独自の丸め誤差があり、この誤差は証拠の対象の外にあります。また、レイの構築に渡す許容値 0 は、数値で表した方向が零ベクトルでないことを検査するための値です。

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-cad-view = "0.3"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。

```toml
[dependencies]
neco-cad-view = { version = "0.3", default-features = false }
```

## 依存クレート

* [`neco-cad`](https://docs.rs/neco-cad): 適応面分割の結果とメッシュの識別子
* [`neco-bigint`](https://docs.rs/neco-bigint): 曲面残差の上界を表す厳密な二進有理数
* [`neco-brep`](https://docs.rs/neco-brep): 境界表現の要素
* [`neco-tessellation`](https://docs.rs/neco-tessellation): 面分割後の形状
* [`neco-mesh`](https://docs.rs/neco-mesh): 検証済みの曲面メッシュ
* [`neco-geometry`](https://docs.rs/neco-geometry): 検査済みのレイと幾何の失敗
* [`neco-nurbs`](https://docs.rs/neco-nurbs): 曲面の制御点と識別子
* [`libm`](https://docs.rs/libm): 二つのランタイム構成で共通に使う正接と平方根
