# neco-mesh

[English](README.md)

`neco-mesh` は、検証済みの曲面メッシュと三角形メッシュの型を提供するクレートです。検証に失敗した入力には、型付きの失敗を返します。

## 主要機能

**曲面メッシュ**

曲面メッシュは、頂点の座標と、各三角形が参照する頂点の番号 ( インデックス ) から成ります。構成時には、すべての番号が頂点の個数より小さいことと、三角形が退化していないことを検証します。

**三角形メッシュ**

三角形メッシュは、三角形分割と面分割で使う、平面上の三角形のメッシュです。

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-mesh = "0.3"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。

```toml
[dependencies]
neco-mesh = { version = "0.3", default-features = false }
```
